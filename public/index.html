    Tips for better results
    • Separate photos beat one big collage. A collage gets shrunk, so fine prints blur.
    • A Word file with one picture per look works well: each picture is read on its own. A PDF is read page by page, like a collage.
    • Make sure every piece is visible. A top under a jacket is easy to miss.
    • Plain backgrounds and daylight help.
